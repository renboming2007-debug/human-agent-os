# 人类 Agent 使用指南 04：你以为发现了商机，其实可能只是 Hallucination

> 版本说明：根据当前对话可见正文整理的 GitHub 阅读版，非 X 原帖逐字转录。

最近研究 AI Agent，我发现一个挺讽刺的现象：我们总担心 AI 一本正经地胡说八道，却很少怀疑自己是不是也在产生幻觉。

“这个赛道绝对是风口。”“别人能赚钱，我应该也能。”看到别人靠 Vibe Coding 月入过万，立刻准备开发爆款 SaaS。三天后产品还没做出来，估值已经在脑子里翻了三倍。

Hallucination：High。
Reality Check：Offline。

## 01｜把可能性当成确定性

看到有人靠 AI 工具赚钱，就觉得 AI 工具很好赚钱；看到有人快速涨粉，就认为自媒体涨粉很容易。但我们只看到了结果，没看到技术能力、流量来源、资源和试错成本。

**一个成功案例，不等于一条经过验证的成功公式。**

## 02｜最危险的幻觉，是用逻辑代替证据

AI 越来越普及，大家需要效率工具，所以做 AI 工具一定有市场。逻辑似乎合理，但谁需要？解决什么问题？现有工具为什么不够？用户愿意付多少钱？

**商业故事讲得完整，不代表商业模式真实。** 用户不会因为你的逻辑自洽就自动付费。

## 03｜建立 Evidence Check

**Evidence：** 判断有什么真实依据？“用户需要 X 数据分析工具”，至少要看到真实用户反复提出相关需求。

**Assumption：** 哪些部分没验证？用户有需求，不代表愿意付费；愿意使用，不代表愿意长期使用。

**Validation：** 能否低成本测试？先做 MVP，找真实用户体验，再考虑收费。

## 04｜别把流量幻觉当成商业能力

播放量高 ≠ 内容有价值。
粉丝增长 ≠ 用户信任。
用户信任 ≠ 商业变现。

Tool Call Success ≠ Task Success。
**Traffic ≠ Trust ≠ Revenue。**

## 05｜Anti-Hallucination Protocol

```md
Evidence: 重要判断寻找事实依据。
Assumption: 标记未经验证的假设。
Validation: 优先低成本实验。
Confidence: 不把可能性当成确定性。
Feedback: 根据真实反馈更新判断。
Stop: 核心假设被否定时及时调整。
```

## 06｜允许自己被证伪

真正重要的能力，不是永远判断正确，而是及时发现自己判断错了。现实世界不会因为你的 Prompt 写得足够坚定，就按照你的预期运行。

我看到的是事实还是故事？我掌握的是证据还是猜测？我是在验证需求，还是寻找支持自己想法的信息？

Hallucination：Detected。
Evidence：Required。
Reality Check：Online。
