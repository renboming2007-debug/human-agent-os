# 人类 Agent 使用指南 03：你不是想得不够多，而是 Thinking 模式用错了

> 版本说明：根据历史对话主题与已知内容重建的整理版，未与 X 原帖逐字核对。

研究 AI Agent 时，我发现一个熟悉的毛病：简单任务反复分析，重要决定反而凭一时兴奋。

写一条帖子，纠结半小时标题；看到别人晒收入，却十分钟决定投入一个新项目。

Thinking Budget：Misallocated。

## 01｜不是所有问题都值得深度推理

AI 系统可以根据任务复杂度分配推理资源。人也应该这样做。

低风险、可逆的事：先做再改。
高风险、难逆转的事：收集证据，认真验证。

一条普通内容发出去效果不好，可以修改下一篇；投入几个月开发没人需要的产品，成本就大得多。

## 02｜把任务分成三档

**Fast Mode：** 日常回复、简单整理、低风险尝试。给自己短时间限制，直接执行。

**Standard Mode：** 写文章、设计小功能、安排本周计划。列出两三个方案，选一个试。

**Deep Mode：** 大额投入、职业转向、长期合作。明确假设、寻找反证、计算退出成本。

## 03｜警惕 Analysis Paralysis

有时候我们说“我还需要再研究一下”，其实只是在推迟面对现实反馈。

分析可以降低不确定性，却不能消除所有不确定性。没有截止条件的思考，很容易无限续费。

我现在会提前设定：什么时候必须做决定？需要哪些最低证据？如果失败，如何止损？

## 04｜思考的终点应该是行动

比如想开发 AI 工具，与其花两周比较所有框架，不如先定义一个可运行的最小功能。真正会改变判断的信息，往往来自用户测试，而不是第 27 篇教程。

**Thinking 不是越多越好，而是把推理预算花在值得推理的地方。**

Fast：可逆任务。
Deep：高代价决策。
Stop Condition：Enabled。
