# 人类 Agent 使用指南 01：你不是不够自律，而是 Token 预算爆了

最近研究 AI Agent，我发现一个挺讽刺的问题：我们知道大模型的 Token 有限，却总觉得自己的精力无限。

早上学编程，下午研究 AI，晚上运营自媒体，睡前还要提升认知。计划写完，感觉人生已经成功了一半。第二天忙着回消息、研究新工具、刷 X，核心任务一项没动。

Executor：Offline。

## 01｜人类也有 Token Budget

人脑当然不是语言模型，Token 只是类比。但注意力和精力确实有限。写代码、深度创作、复杂决策的认知消耗不同。计划只计算时间、不计算消耗，就容易超载。

## 02｜Context Switching 才是隐形成本

准备写代码，收到消息；回复后打开 X，看到新工具；顺手研究 GitHub，两个小时过去代码还在第一行。看起来一直在学习，实际一直在切换上下文。

我的规则：执行阶段，新灵感不自动获得最高优先级。先写进 Inbox，再回到当前任务。

## 03｜别追求每天 100% 利用率

我们常用理想状态下的自己给现实中的自己排班。一个任务超时，后面的计划全部崩溃。好的预算需要缓冲，低功耗不代表失败。

## 04｜建立 Human Token Budget

- High Cost：编程、复杂决策、深度创作。
- Medium Cost：修改文案、整理资料、常规沟通。
- Low Cost：归档、检查、更新状态。

每天先完成一个 High Cost 核心任务。把“研究 AI 产品”改成“完成 CSV 导入和增长趋势图”。任务要有可验证的产出。

## 05｜恢复机制

Normal：执行核心任务。
Low Power：减少任务，只做必要工作。
Recovery：暂停非必要任务，优先恢复。

**AI Agent 需要管理 Token，人类需要管理注意力。** 效率不是为了把自己压榨到极限，而是减少无意义消耗，把时间留给真正重要的事情。

System Status：Running
Token Budget：Limited
Priority：One Thing at a Time
