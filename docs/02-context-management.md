# 人类 Agent 使用指南 02：你不是信息不够，而是 Context 已经过载

每天打开 X、GitHub、新闻和各种 AI 工具，感觉自己正在疯狂进步。到了晚上，却很难说出今天到底完成了什么。

Context：Overflow。
Output：Pending。

## 01｜信息多，不等于理解深

AI Agent 的上下文窗口有限；人类的工作记忆也有限，但两者不是同一种机制。不断塞入新信息，不会自动变成能力。看过十篇教程，不等于能独立完成一个项目。

## 02｜每一次切换，都有重新加载成本

准备开发工具，看到一个新模型发布，转去研究；看到别人分享赚钱案例，又开始重新规划赛道。我们以为自己在寻找最优解，其实是在不断重置工作现场。

我给自己加了一条规则：**新信息先进入 Inbox，不直接改写当天的优先级。**

## 03｜建立三层 Context

**Active Context：** 当前唯一需要推进的任务、完成标准和下一步。

**Reference Context：** 做任务时可能用到的资料、链接、代码与案例。

**Archive Context：** 暂时不需要，但值得保存的历史信息。

不必把所有信息同时摆在眼前。需要时再检索，而不是让每条推送都来参加决策会议。

## 04｜一次只保留必要上下文

例如开发 X 数据分析工具，今天只关心：CSV 格式、导入是否成功、图表是否正确。商业模式、品牌设计、未来定价可以放进待办列表。

如果一个信息不能帮助当前任务推进，就暂时不让它占据 Active Context。

## 05｜给自己设置上下文清理

每天开始前写下：
- 当前目标是什么？
- 下一步动作是什么？
- 哪些干扰先不处理？

每周清理 Inbox：删除无效灵感、归档参考资料、挑出真正值得验证的想法。

**你缺的可能不是更多知识，而是一个让重要信息持续留在注意力中心的机制。**

Context：Focused。
Noise：Reduced。
Next Action：Clear。
