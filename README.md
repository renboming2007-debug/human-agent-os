## 使用方法

从第一篇开始阅读，复制 [HUMAN_AGENTS.md](HUMAN_AGENTS.md) 作为个人操作手册，并使用 [每日复盘](templates/daily-review.md)、[每周复盘](templates/weekly-review.md)、[记忆模板](templates/memory.md) 和 [AI 项目示例](examples/ai-side-project.md)。

核心循环：**Goal → Plan → Execute → Feedback → Memory → Update**。
